# Smart Lost and Found System for College Campus

## Project Overview
This project explores an AI-assisted approach to matching lost and found items on a college campus using images and item attributes.

## Dataset
The `smart_lost_found_dataset.csv` file contains a synthetic dataset generated using Python in Google Colab for experimentation.

- **Objects:** 200
- **Records:** 600
- **Matching pairs:** 400

The records include item-related attributes such as category, colour, location, and time.

## Experiments
The `Smart_Lost_Found_Experiments.ipynb` notebook contains the Python code used for the project experiments.

## Repository Contents
- `smart_lost_found_dataset.csv` — Synthetic dataset.
- `Smart_Lost_Found_Experiments.ipynb` — Experiment notebook.

## Note
The dataset is synthetic and was generated for project experimentation. It should not be interpreted as a collection of actual campus lost-and-found reports.
